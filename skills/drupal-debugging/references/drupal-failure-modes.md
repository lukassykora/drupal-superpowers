# Drupal failure families

| Family | Typical symptom | Where the cause usually is | Diagnostic (read-only unless noted) |
|---|---|---|---|
| Container / service | `ServiceNotFoundException`, `You have requested a non-existent service`, class not found on `drush cr`, WSOD after enabling a module | `*.services.yml` argument IDs (`entity.manager` → `entity_type.manager`), class namespace vs file path, missing `dependencies:` in info.yml, circular references | `drush cr` output; `grep -rn "<service id>:" <docroot>/core/**/*.services.yml`; `drush php:eval "\Drupal::service('id');"` |
| Plugin discovery | "The X plugin does not exist", block missing from the UI, field type unknown | attribute vs annotation for this version, wrong `Plugin/<Type>` subdirectory, class namespace, stale discovery cache, `deriver` errors | `drush cr`; `drush php:eval "print_r(array_keys(\Drupal::service('plugin.manager.<type>')->getDefinitions()));"` |
| Routing | 404 on a new path, "Route does not exist" in `Url::fromRoute`, `_controller` not callable | `routing.yml` name/path, missing `drush cr` (router rebuild), parameter converter, requirement regex, method restriction | `drush route` / `drush route --path=/x`; check `_format`, `methods` |
| Access | 403 for a role that should pass; 200 for one that should not | route requirement (`_permission` string typo), entity access handler, `hook_entity_access`, node grants, field access, `accessCheck(FALSE)` | `drush user:information <name>`, `drush role:list --filter='rid=<role>'`; test with `$entity->access('view', $account, TRUE)` returning `AccessResult` and its reason |
| Config schema / drift | "Missing schema", `cim` fails with dependency/UUID errors, kernel test fails on schema | `config/schema` missing keys, config depending on an uninstalled module, `uuid` mismatch after reinstall, config split not active | `drush config:status`; `drush cim --diff --no`; `drush config:inspect` (contrib config_inspector) |
| Render / cache | stale content, another user's data, changes visible only after `cr`, wrong language | missing cache contexts/tags/max-age, lazy builder without contexts, `#cache` on the wrong element, Internal Page Cache serving anonymous | see `drupal-cacheability`; `X-Drupal-Cache`, `X-Drupal-Dynamic-Cache` headers; `drush cache:tags` |
| Twig / theme | template not used, `{{ variable }}` empty, theme hook missing | `hook_theme` definition/variables, template file name (`underscores → dashes`), suggestions, Twig cache, theme registry | `drush cr`; enable Twig debug on LOCAL (`sites/development.services.yml`); `drush theme:list`? (contrib) |
| Libraries / JS | script not loading, behaviour runs twice, `once` undefined | `*.libraries.yml` path/dependencies, `#attached` missing, aggregation, `core/once` dependency, behaviour attach without `once()` | browser network tab, `drush state:get asset.css_js_query_string`, disable aggregation on LOCAL |
| AJAX | callback returns nothing / whole page, 500 in AJAX request | wrapper ID mismatch, callback not returning the element, form rebuild, access on the AJAX route | browser network response body; `drush watchdog:show` |
| Queue / cron | items never processed, cron slow/timing out | worker plugin missing/failing, `cron` time limit, lease time, `ultimate_cron` config | `drush queue:list`, `drush queue:run <name>` (LOCAL), `drush cron` with `--debug` |
| Update / post-update | `drush updb` fails, site stuck in maintenance | update hook number, non-idempotent update, entity definition update, config in update hook | `drush updatedb:status` (pending updates, read-only); `drush updb` itself runs them (no dry-run flag; `-n` is Symfony `--no-interaction` and auto-confirms) |
| Database schema | "Unknown column", entity field missing on the site | new base field without `installFieldStorageDefinition` update, `hook_schema` change without update hook | `drush entity:updates` (deprecated/absent in newer core) → `drush php:eval` with `entityDefinitionUpdateManager()->getChangeSummary()` |
| Migrations | rows skipped, idmap stale, "Migration is busy" | source query, process pipeline, `migrate_map` state, dependencies order | `drush migrate:status`, `drush migrate:messages <id>`, `drush migrate:reset-status <id>` (write) |
| Multilingual / revisions | wrong translation shown, latest revision not visible | missing `langcode` condition / `languages:language_interface` context, content_moderation default revision, `loadRevision` | entity query with langcode; `drush content:… ` inspection via `php:eval` |
| Composer / patches | update fails, patch does not apply, class missing after update | constraint conflicts, patch drift, `composer-patches` v1 vs v2 config, dependency requiring a newer core | `composer why-not`, `composer show -t`, `composer validate`, patch `--dry-run` |
| Deprecations / Symfony | tests fail on deprecation, fatal after core update | removed API (see facts registry), Symfony signature changes, PHP version | `drupal-facts list <version>`, phpstan with deprecation rules, `drupal-lookup <symbol>` |
| PHP / hosting | WSOD with no log, memory exhausted, timeouts | `error_level` hidden, `memory_limit`, opcache stale, file permissions on `sites/default/files` | PHP error log via runtime; `drush core:requirements` |

Always confirm the family from the evidence, not the symptom alone: a "403" can be routing (wrong route matched), access, or cache (a cached 403).
